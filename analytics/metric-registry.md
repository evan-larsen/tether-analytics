# Metric Registry

Only metrics that are currently used in an existing dashboard or in the current approved dashboard batch belong here.

| Name | Definition | Event / property logic | Identifier | Important caveat |
| --- | --- | --- | --- | --- |
| New users | Net-new onboarding entrants | Pull from `cohort_new_users` | `distinct_id` | Materialized rolling 90 complete-day cohort recomputed hourly; PostHog supports cadence but not an exact run time. Check the cohort view itself for the exact SQL definition. |
| Current active subscriptions | Distinct subscriptions with entitlement access right now | Pull the latest Production RevenueCat lifecycle state per `original_transaction_id`; count rows where `expires_at >= now()` | `original_transaction_id` | Intraday live-state metric, not a complete-day snapshot. Uses latest known lifecycle state and changes immediately as new events arrive. |
| DAU Subscribed % (7d Avg Rolling) | Share of average full daily active users across the last 7 complete days who had an active subscription on those same days | Last 7 complete US/Mountain days of distinct `user_analytics_id` across all events, joined day-by-day to `subscription_active_daily_snapshots`; saved insight formatted as `percent` | `user_analytics_id` | Excludes today. This is average subscribed full DAU divided by average full DAU across the last 7 complete days, not today's intraday DAU. |
| MAU Subscribed % (30d Rolling) | Share of full rolling 30-day active users across the last 30 complete days who were active subscribers as of yesterday | Last 30 complete US/Mountain days of distinct `user_analytics_id` across all events, intersected with yesterday's `subscription_active_daily_snapshots`; saved insight formatted as `percent` | `user_analytics_id` | Excludes today. Denominator is full rolling 30-day MAU through yesterday, and subscriber status is anchored to yesterday's completed-day snapshot. |
| Active subscriptions | Distinct subscriptions with entitlement access at the end of each complete day | Pull from `subscription_active_daily_snapshots`; group by `snapshot_day` and count distinct `original_transaction_id` | `original_transaction_id` | Subscription-level state metric, not supporter count. `subscription_cancelled` remains active until `expires_at`. Backed by the hourly 90-day materialized snapshot view. |
| Habit-forming users | Highest qualifying reader-habit tier: at least 3 distinct active days in the preceding 7 complete days | Pull from virtual `cohort_habit_forming_users`; group by `snapshot_day` | `user_analytics_id` | Exclusive rolling-state tier: excludes Establishing, Active, and Near-daily users; backed by the hourly 90-day materialized source. |
| Establishing readers | Highest qualifying reader-habit tier: at least 7 distinct active days in the preceding 14 complete days | Pull from virtual `cohort_habit_establishing_readers`; group by `snapshot_day` | `user_analytics_id` | Exclusive rolling-state tier: excludes Active and Near-daily users; backed by the hourly 90-day materialized source. |
| Active readers | Highest qualifying reader-habit tier: 18 to 24 distinct active days in the preceding 30 complete days | Pull from virtual `cohort_habit_active_readers`; group by `snapshot_day` | `user_analytics_id` | Exclusive rolling-state tier backed by the hourly 90-day materialized source, which scans 120 days of source events. |
| Near-daily readers | Highest qualifying reader-habit tier: at least 25 distinct active days in the preceding 30 complete days | Pull from virtual `cohort_habit_near_daily_readers`; group by `snapshot_day` | `user_analytics_id` | Exclusive rolling-state tier backed by the hourly 90-day materialized source, which scans 120 days of source events. |
| Pre-habit daily active readers | Canonical DAU not assigned to a reader-habit tier | Pull from virtual `cohort_habit_pre_habit_readers`; it is distinct `user_analytics_id` on `reading_session_completed` minus the four exclusive tiers on the same `snapshot_day` | `user_analytics_id` | Reusable virtual cohort; may include brand-new or returning low-frequency readers and is not the acquisition `New users` cohort. |
| Completed onboarding | Users who finish start selection | `onboarding_start_selection_completed` | `user_analytics_id` | If the funnel includes first open, bridge from `distinct_id` in SQL |
| Activated users | Post-commit onboarding users who complete a first reading session | `onboarding_intro_completed` -> first `reading_session_completed`, usually with `session_source = 'onboarding'` | `user_analytics_id` | If anchored on first open, the funnel is stitched, not purely canonical |
| Started reading sessions | Unique reading sessions that start | `count(distinct properties.session_id)` on `reading_session_started` | `session_id` | Deduplicate raw events |
| Completed reading sessions | Unique reading sessions that complete | `count(distinct properties.session_id)` on `reading_session_completed` | `session_id` | Deduplicate raw events |
| Active users | Users with at least one event in the window | Distinct `user_analytics_id` across all events | `user_analytics_id` | Full activity includes any captured event; use Completion active users for meaningful reading activity |
| DAU | Full daily active users | Distinct `user_analytics_id` across all events per day | `user_analytics_id` | Full activity metric; not limited to reading completion |
| WAU | Full weekly active users | Distinct `user_analytics_id` across all events in trailing 7 days | `user_analytics_id` | Full activity metric; not limited to reading completion |
| MAU | Full monthly active users | Distinct `user_analytics_id` across all events in trailing 30 days | `user_analytics_id` | Full activity metric; not limited to reading completion |
| Completion active users | Users who complete at least one reading session in the window | Distinct `user_analytics_id` on `reading_session_completed` | `user_analytics_id` | Canonical meaningful-activity metric; requires app version `1.6.0+` |
| Completion DAU | Daily active users who complete a reading session | Distinct `user_analytics_id` on `reading_session_completed` per day | `user_analytics_id` | Meaningful reading activity, not full DAU |
| Completion WAU | Weekly active users who complete a reading session | Distinct `user_analytics_id` on `reading_session_completed` in trailing 7 days | `user_analytics_id` | Meaningful reading activity, not full WAU |
| Completion MAU | Monthly active users who complete a reading session | Distinct `user_analytics_id` on `reading_session_completed` in trailing 30 days | `user_analytics_id` | Meaningful reading activity, not full MAU |
| Session completion rate | Share of started sessions that complete | Deduped completed `session_id` / deduped started `session_id` | `session_id` | Must compare deduped sessions, not raw event totals |
| Verses read | Total verses completed in sessions | Sum `session_verse_count` on `reading_session_completed` | `session_id` | Session-level output metric, not user count |
| Executive D1 retention | New users with any event on exact day 1 | `cohort_new_users`; any event on day 1 | `distinct_id` | Last 14 fully completed D1 cohorts |
| Executive D7–13 retention | New users with any event in days 7 through 13 | `cohort_new_users`; any event in the fixed D7–13 window | `distinct_id` | Last 14 cohorts whose full D7–13 window has completed |
| Executive D14–29 retention | New users with any event in days 14 through 29 | `cohort_new_users`; any event in the fixed D14–29 window | `distinct_id` | Last 30 cohorts whose full D14–29 window has completed |
| Executive D30–59 retention | New users with any event in days 30 through 59 | `cohort_new_users`; any event in the fixed D30–59 window | `distinct_id` | Last 30 cohorts whose full D30–59 window has completed |
| Early retention trend (7d) | Responsive, user-weighted rolling new-user retention | Fixed milestone windows: D1, D5–7, D12–14, and D28–30 | `distinct_id` | Each point is the ratio of retained to eligible users across the latest 7 completed cohort days; x-axis is the return-window completion date |
| Current streak | Latest observed streak for a recent user | Latest `current_streak`, fallback `streak_count_at_event` | `user_analytics_id` | Snapshot metric; only as current as the latest emitted event |
| Streak started | Users whose streak moved from 0 to 1 | `reading_session_completed` where `did_streak_increment = true` and `streak_days_after = 1` | `user_analytics_id` | Canonical metric requires app version `1.6.0+` |
| Streak continued | Users whose existing streak extended | `reading_session_completed` where `did_streak_increment = true` and `streak_days_after > 1` | `user_analytics_id` | Canonical metric requires app version `1.6.0+` |
| Streak lost | Users whose streak broke | `streak_lost` | `user_analytics_id` | Measures emitted streak-loss detection, not an independent state table |
| Streak freeze conversion | Users shown a freeze prompt who use a freeze | `streak_freeze_prompt_shown` -> `streak_freeze_used` | `user_analytics_id` | Query carefully by user and time window, not raw event count alone |
